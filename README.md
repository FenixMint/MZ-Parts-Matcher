# MZ-Parts-Matcher

MZ-Parts-Matcher to narzędzie wspierające przygotowanie ofert części motoryzacyjnych na Allegro.

Aplikacja wykorzystuje Allegro REST API do odczytu informacji z katalogu produktów i wspomaga identyfikację produktów przed przygotowaniem oferty.

Repozytorium pełni funkcję publicznej strony informacyjnej aplikacji.

Nie zawiera danych uwierzytelniających, danych klientów, prywatnych danych handlowych ani konfiguracji środowiska produkcyjnego.
